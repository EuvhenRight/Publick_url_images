## Instructions for interviewers

1. Score only the candidate’s answers, work samples, and job-related evidence.
2. Do not score appearance, attractiveness, hairstyle, body type, age appearance, clothing style, tattoos, piercings, or perceived “fit” unless a written, job-related requirement applies.
3. If you mention “professionalism,” “polish,” “executive presence,” or “client-ready,” explain the specific job-related behavior you observed.
4. Use the same core questions for each candidate.
5. Complete your scores before discussing the candidate with other interviewers.

## Scoring scale

| Score | Meaning |
|---|---|
| 1 | Does not meet the requirement based on available evidence |
| 2 | Partially meets the requirement; significant gaps remain |
| 3 | Meets the requirement |
| 4 | Exceeds the requirement |
| 5 | Far exceeds the requirement with strong evidence |

## Bias check before submission

Answer each question before finalizing feedback:

- Did I rely on the same core criteria used for other candidates?
- Did I document evidence rather than impressions?
- Did I use terms like “fit,” “polish,” “professional,” or “executive presence”? If yes, did I define the specific behavior?
- Did any appearance-related factor influence my evaluation?
- Would I make the same comment if the candidate had a different gender, race, age, body type, hairstyle, disability, class background, or style of dress?

## Final notes for hiring team

If feedback includes subjective appearance-coded language, pause the decision discussion and ask for job-related evidence before proceeding.

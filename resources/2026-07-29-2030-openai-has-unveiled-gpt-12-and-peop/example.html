Center a <div> (or a button) — every reliable way

Open this file in any browser. Each box uses a different technique.

1. Flexbox — both axes

display:flex; justify-content:center; align-items:center;

2. Grid — both axes (shortest)

display:grid; place-items:center;

3. Absolute + transform (for overlays/modals)

position:absolute; top:50%; left:50%; transform:translate(-50%,-50%);

4. margin-inline:auto — horizontal only

display:block; margin-inline:auto;
